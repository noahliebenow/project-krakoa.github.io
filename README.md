## 📝 Customization

To customize the website:

1. Edit `index.html` to update content and sections
2. Modify `style.css` to change colors, fonts, or layout
3. Update the color variables in `style.css`:
   - `--primary-color`: Main accent color (currently indigo)
   - `--secondary-color`: Secondary accent color (currently pink)
